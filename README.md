# RETROVA

A personal retro gaming library for games supplied by each user.

## Status

Initial frontend foundation. This repository currently contains the visual dashboard and client-side interaction prototype only. Authentication, private ROM storage, metadata identification, browser emulation, cloud saves, achievements, and social features are not yet implemented.

## Development

```bash
npm install
npm run dev
```

## Stack

- React
- TypeScript
- Vite
- CSS

ROM files must remain private to their owner. Do not commit ROMs or copyrighted game assets to this repository.
